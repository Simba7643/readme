## 🤖 Robot Motion Architecture

```text
PS — Primitive Standard
├── side_move()
├── lift_move()
├── twist_move()
└── smooth_move()

SS — Secondary Standard
├── motion3()
├── wave_motion()
├── upper_arm_motion()
└── back_motion()

CHAIN
├── PS chains
└── SS chains
    └── timing / sequencing / pause / return

C Motion Library
        ↓
robot_motion.dll
        ↓
ctypes
        ↓
Python + VPython
        ↓
3D Robot Display
```

The same reusable C motion logic can later be compiled into MCU firmware, while Python remains the visualization layer.
